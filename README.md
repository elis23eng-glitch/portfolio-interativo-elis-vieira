# Portfólio Interativo — Elis Vieira

Portfólio profissional desenvolvido para apresentar, de forma visual e interativa, uma trajetória que conecta **Engenharia Civil, Gestão de Processos, Projetos, Indicadores, Dados e Tecnologia**.

> O projeto prioriza clareza, experiência do visitante, privacidade e evolução contínua. Nomes de empresas, cargos anteriores, contatos pessoais e outras informações sensíveis não são exibidos.

## Demonstração

[Acessar o portfólio](https://elis-vieira-trajetoria.elis23-eng.chatgpt.site)

O acesso à versão atual pode exigir autenticação com o ChatGPT.

## Objetivos

- Consolidar formação, competências e resultados em uma narrativa profissional única.
- Demonstrar capacidade de transformar dados e experiências em comunicação executiva.
- Apresentar avaliações comportamentais de maneira visual e responsável.
- Reunir projetos digitais em um ambiente preparado para expansão.
- Aplicar programação, inteligência artificial, visualização de dados e experiência do usuário em um produto real.

## Funcionalidades

- Avatar digital com apresentação em voz utilizando a Web Speech API.
- Navegação responsiva para computador e celular.
- Dashboard do perfil Analista Planejador.
- Visualização do SVA — Índice de Atitude e competências avaliadas.
- Linha do tempo interativa da trajetória profissional.
- Cards de projetos com acesso às demonstrações.
- Animações ativadas durante a navegação.
- Respeito à preferência do sistema por redução de movimentos.
- Controles acessíveis por teclado e estados informados por atributos ARIA.

## Executar localmente

O projeto é estático e não exige instalação de dependências.

```bash
python -m http.server 8000 --directory dist
```

Depois, abra `http://localhost:8000` no navegador.

## Privacidade

- Não são exibidos telefone, e-mail, endereço ou documentos pessoais.
- A trajetória é apresentada sem identificar empresas e cargos anteriores.
- O avatar foi criado a partir de imagem autorizada pela titular do portfólio.
- O site não possui formulário de coleta de dados.
